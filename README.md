# Marketplace – Peer-to-Peer-Verleihmarktplatz Berlin

Online-Marktplatz, auf dem Privatpersonen selten genutzte Gegenstände (Häcksler, Dachgepäckträger, Werkzeug, Freizeitgeräte) an andere verleihen. Mieter wählen aus mehreren Angeboten, Verleiher erhalten die Miete, die Plattform behält eine Gebühr.
